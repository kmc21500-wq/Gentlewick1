# Gentlewick — Independent Hosting Copy

This is a working copy prepared for hosting outside Grok. The original uploaded ZIP and the initial staging copy are untouched.

The Grok-specific preview, authentication, connector, PWA install, and workspace tooling have been removed from this copy. A standard web manifest and Apple touch icon are now included.

**This copy is not yet confirmed deployable:** dependency installation and production build testing still need to run in an environment with npm registry access. Memorials and orders remain browser-local and are not yet backed by online storage or payment processing.
